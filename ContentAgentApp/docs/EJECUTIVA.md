# Documentación ejecutiva — ContentAgentApp v3

## Resumen
ContentAgentApp es una aplicación pensada para acelerar la planificación de contenido digital a partir de un brief simple.

Su propósito es convertir información básica de un proyecto en una propuesta inicial de contenido, lista para trabajar, sin depender de procesos manuales largos.

## Problema que resuelve
Muchas personas, marcas y equipos pequeños saben que necesitan contenido, pero pierden tiempo en:
- definir por dónde empezar
- traducir su oferta en mensajes claros
- generar ideas de publicación
- organizar un calendario inicial
- mantener consistencia entre objetivo, tono y canal

El resultado suele ser improvisación, lentitud y poca claridad estratégica.

## Solución propuesta
ContentAgentApp toma un brief corto del proyecto y lo transforma en una salida estructurada que ayuda a arrancar más rápido.

La aplicación organiza la información y genera una base útil para producción de contenido.

## Qué hace hoy la v3
La versión actual permite:
- capturar contexto del proyecto
- definir nicho, audiencia, objetivo, canal y tono
- generar una propuesta de posicionamiento
- generar 5 ideas iniciales de contenido
- construir un calendario semanal simple
- sugerir un CTA alineado con la oferta
- guardar la información localmente para seguir trabajando después

## Valor que entrega
### 1. Reduce tiempo de arranque
Evita empezar desde cero cada vez que se quiere planificar contenido.

### 2. Ordena el pensamiento estratégico
Convierte información dispersa en una estructura clara y accionable.

### 3. Facilita consistencia
Mantiene alineados objetivo, audiencia, tono y canal dentro de una misma propuesta.

### 4. Sirve como base para evolución
La versión actual ya funciona como MVP y deja lista una base para crecer hacia automatización real.
